# Shimeji

Кроссплатформенный desktop buddy на Qt/PySide6: спрайты показываются в масштабе 3x
с сохранением прозрачного альфа-канала. Персонаж стоит на `stay1.png`, случайно
выбирает между отдыхом 8-15 секунд и прогулкой влево/вправо. Во время отдыха
редко на 350 мс появляется `stay_walk.png`. Кадры ходьбы начинаются с
`walk_*_s.png`, затем повторяют `walk_*_1.png` - `walk_*_4.png` и возвращаются
к стойке. Удерживайте левую кнопку, чтобы схватить персонажа за голову и двигать
его; при движении влево спрайт зеркалится, а тело раскачивается против движения.
Отпустите кнопку, чтобы запустить падение: `fall1`, `fall2`, `fall3`, затем
`fall_floor` при посадке на пол или `fall_window` при посадке на окно приложения.
После короткой паузы на полу персонаж встаёт через обратные кадры падения;
оконная посадка опущена на четверть высоты спрайта относительно верхнего края окна.
Если окно унести или закрыть, персонаж заметит потерю опоры и снова упадёт.
`fall3_alt` редко заменяет третий кадр, `fall4_alt` редко проигрывается перед
посадкой на окно. Правый клик открывает паузу и выход.

## Запуск

Установите PySide6. В Arch Linux:

```sh
sudo pacman -S pyside6
```

На Windows, macOS или других Linux-дистрибутивах через pip:

```sh
python -m pip install PySide6
```

Запустите из папки со спрайтами:

```sh
python shimeji.py
```

## Linux AppImage

Для сборки автономного x86_64 AppImage нужен Docker Desktop с Linux engine:

```sh
bash packaging/linux/build-appimage.sh
```

Готовый файл для Linux x86_64 появится в `dist/Shimeji-x86_64.AppImage`. Его можно
передать на другой Linux-компьютер; Python, PySide6, Qt, все PNG-спрайты, цитаты
и шрифт уже включены. На целевой системе не нужно устанавливать пакеты Python или
скачивать ресурсы.

## Arch Linux

Для установки как нативного пакета Arch нужны `base-devel` и `pyside6`:

```sh
sudo pacman -S --needed base-devel pyside6
cd packaging/arch
makepkg -si
```

После установки запустите `shimeji` из меню приложений или терминала. Пакет
устанавливает все спрайты, цитаты и шрифт вместе с приложением; для удаления:

```sh
sudo pacman -Rns shimeji-desktop-buddy
```

Посмотреть последовательности кадров без запуска окна:

```sh
python shimeji.py --show-sequence
```

Окна под персонажем определяются на Windows и X11. В Wayland, где приложениям
недоступен список чужих окон, используется посадка на пол. Окну нужен XWayland.
Прозрачные пиксели спрайтов
используются напрямую через Qt per-pixel alpha, без цветового ключа, который мог
бы создавать цветные ореолы по контуру.

В контекстном меню выберите `mod_prog`: кадры 1 и 2 проигрываются с обычным
интервалом, затем кадры 3 и 4 повторяются в четыре раза медленнее. Выберите
`End mod_prog`, чтобы выйти через кадры 2 и 1.

В контекстном меню можно выбрать `mod_ksp`: кадр 1 показывается 5 секунд, затем
кадры 2 и 3 чередуются каждые 1,5 секунды. Затем кадр 1 и `mod_ksp_alarm`
независимо появляются в случайные моменты через 20 секунд — 5 минут; каждый
показывается 5 секунд, после чего цикл продолжается. `End mod_ksp` завершает режим.

Только пока активен `mod_prog`, примерно раз в минуту от случайного края монитора
начинает расти новая ветвящаяся проволока. Вне режима генерация и рост
приостанавливаются, уже нарисованные провода остаются на экране. `Clear wires`
очищает их и запускает минутный интервал заново. При захвате персонажа рост тоже
останавливается. Слой следует за монитором, на котором находится персонаж;
при переносе на другой монитор прежние провода очищаются.

Двойной или тройной клик левой кнопкой показывает случайную цитату из `words.txt`.
Каждая непустая строка файла считается отдельной репликой.
Цитата отображается в белом пиксельном пузыре с прозрачным внешним фоном и
шрифтом Press Start 2P; размер пузыря подстраивается под текст.
